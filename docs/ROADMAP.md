# 차기 버전 계획 (ROADMAP)

v1.1.0 이후에 넣을 기능 후보. 사용자가 2026-10-30에 "차기 버전업 기능"으로 정함. 순서·범위는 시작할 때 다시 정한다.

| # | 기능 | 내용 | 고려할 점 |
| --- | --- | --- | --- |
| 1 | 영어 화면 | `src/strings.ts`를 언어별로 나누고 브라우저 언어로 자동 선택, 화면에서 바꾸기 | 오류·안내 문구 전부 번역, `<html lang>` 변경 |
| 2 | 여러 파일 한 번에 | 여러 PDF를 차례로 압축, 결과를 하나씩 또는 묶어서(zip) 받기 | 메모리 때문에 동시가 아닌 순서대로 처리, 전체 진행률·개별 취소 |
| 3 | 오프라인 사용 | PWA(설치·홈 화면 추가), 압축 엔진(WASM 약 5MB)을 미리 캐시 | Service Worker와 CSP(`worker-src`) 조정, 버전 바뀔 때 캐시 갱신 |
| 4 | 전후 미리보기 | 원본과 결과의 같은 쪽을 나란히 보여 주기(확대 가능) | 렌더링도 Worker에서, 큰 파일은 첫 쪽만 |

## 함께 확인할 남은 점검 (v1.0.0 T-13 미확인)

- 실제 사진·스캔 PDF로 품질 단계 4~6 화질 재확인
